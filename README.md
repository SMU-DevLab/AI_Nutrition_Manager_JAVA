# AI 기반 개인 맞춤 식단·영양 관리 및 자동 레시피 추천 시스템

사용자가 보유 식재료, 알레르기, 식습관, 목표(다이어트/벌크업 등)를 입력하면 AI(LLM)가 맞춤 레시피를 추천하고, 공공 영양정보 데이터와 연동해 영양소를 정량 분석하여 부족/초과 영양소를 안내하는 웹 서비스입니다.

## 주요 기능

| 구분 | 기능 | 설명 |
|---|---|---|
| 회원 | 회원가입 / 로그인 | 이메일 기반 회원가입, JWT 인증 로그인 |
| 회원 | 프로필 등록 | 신체정보, 목표(다이어트/벌크업/유지) 등록 |
| 입력 | 보유 식재료 입력 | 냉장고 속 재료 등록/수정/삭제 |
| 입력 | 알레르기 정보 입력 | 알레르기 유발 식품 등록 |
| 입력 | 식습관 입력 | 비건/저탄고지 등 식습관 등록 |
| 입력 | 목표 설정 | 목표 유형 및 1일 목표 칼로리·영양소 설정 |
| AI 추천 | 레시피 추천 | 입력 정보 기반 프롬프트로 LLM API 호출, 맞춤 레시피 생성 |
| AI 추천 | 대체 재료 추천 | 알레르기/재료 부족 시 AI가 대체 식재료 제안 |
| 영양 분석 | 영양성분 조회 | 식약처 식품영양성분 DB 연동으로 레시피 영양소 계산 |
| 영양 분석 | 부족 영양소 안내 | 목표 대비 부족/초과 영양소 안내 |
| 통계 | 식단 기록 | 일자별 섭취 식단 기록 |
| 통계 | 통계 및 차트 시각화 | 일별/주별 섭취 칼로리·영양소 통계 차트 |
| 관리 | 즐겨찾기 저장 | 추천 레시피 저장/재조회/재사용 |
| 관리 | 히스토리 조회 | 과거 추천 레시피 및 식단 기록 이력 조회 |
| 식단 직접 입력 | 섭취 음식 직접 기록 | AI 추천 외 실제 섭취 음식 직접 입력 시 영양성분 자동 조회·저장 |

> 각 기능의 상세 설명 및 세부 기능은 `docs/요구사항_정의서_ver2.docx` 참고

## 기술 스택

- **백엔드**: Java 17, Spring Boot
- **데이터 접근**: Spring Data JPA, MySQL
- **AI 연동**: OpenAI / Claude API (Java HTTP Client)
- **외부 API**: 식약처 식품영양성분 DB (공공데이터포털)
- **인증**: Spring Security, JWT
- **프론트엔드**: Thymeleaf 또는 React (택1)
- **빌드/형상관리**: Gradle(Maven), Git/GitHub
- **기타**: Swagger(API 문서), JUnit(테스트)

## 서비스 흐름

1. 사용자가 보유 식재료, 알레르기, 식습관, 목표를 입력
2. 서버가 입력 데이터로 LLM API 호출용 프롬프트 생성
3. LLM API가 레시피(요리명, 재료, 조리 순서) 반환
4. 서버가 응답을 파싱하여 레시피 정보를 DB에 저장
5. 레시피 재료 기준으로 공공 영양정보 API 조회 및 영양성분 계산
6. 목표 영양소와 비교하여 부족/초과 영양소 안내
7. 실제 섭취 식단 기록 시 일별/주별 통계 차트로 시각화

## 브랜치 전략 (제안)

- `main` : 배포 가능한 안정 버전
- `develop` : 기능 통합 브랜치
- `feature/기능명` : 개별 기능 개발 브랜치 (예: `feature/recipe-recommend`, `feature/nutrient-analysis`)

작업 완료 후 `feature/*` → `develop` 으로 Pull Request 생성, 리뷰 후 병합합니다.
